# OpsDone design system

The site uses spacious typography, a warm neutral background, restrained green and clear process illustrations. It explains business outcomes before asking for contact information.

## References

- [Attio](https://attio.com/): clear hierarchy and concrete product/process visualization.
- [OpenAI](https://openai.com/de-DE/): restrained editorial typography and generous space.
- [Navan](https://navan.com/de): direct benefit-led entry and prominent next action.
- [Personio](https://www.personio.de/): approachable B2B language and clear navigation.

These are direction references; no assets, customer logos or customer claims were copied.

## Core choices

- Brand: OpsDone; master claim: Work eliminated.
- Display: Space Grotesk. Body: Manrope. Fonts are served locally.
- Background `#f8f8f5`, text `#1d2420`, green `#275b48`, sage `#e1e8d4`.
- Primary conversion: free process check; secondary: understand a process or calculate capacity.
- Interface examples explicitly use sample data. Existing system names are examples, not partnership badges.
- The calculator shows gross capacity value before implementation/operation costs, not guaranteed cash savings.
- Mobile forms use 16px input text, visible focus, native labels and truthful error states.
